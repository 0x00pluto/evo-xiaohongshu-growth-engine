# v0.9.0

相对 `v0.8.0`：写成笔记只出文案；点风格即选中；点刷新才套整套提示词并画当前张。

## 变更

- **先看文**：写成笔记只出标题、正文、话题，不跑画面策划、不生图。`job.running` 在成稿后为假。
- **点卡即选中**：风格卡只换描边，不再打开详情浮层，也没有「按此风格重算提示词」。没选风格时刷新沿用已套用的图册，还没有则随机抽一本。
- **刷新才套词出图**：点某一张刷新时，若尚未套词或稿面相对 `prompts.basis` 已变，先给整套定画面再只画当前张。稿面未改且同风格不再调策划和第 11 槽模型。换册且文案结构对得上则本地重套 1–10 槽。
- **提示词框**：只展示可改段（第 11 槽与画面上的文案）。未套词时「这张的提示词」不可展开。
- **等待文案**：写文为「正在写这篇笔记」；定画面为「正在定这一套图」；生图为「正在用{图册名}画封面」或「正在用{图册名}画第 N 张」。出图路径不出现「写这篇笔记」。
- **旧像素**：写成笔记不清已有图片；刷新哪张才换哪张。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.9.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.9.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.9.0`
- 写成笔记（`generateDraft`）不再生成提示词和图片；出图改为点刷新走 `generateImages`
