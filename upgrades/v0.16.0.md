# v0.16.0

相对 `v0.15.1`：不能发必须可替换（去掉假放弃）；出厂不能发补齐默认句；并收录截流/自动化相关危险词。

## 变更

- **不能发必须可替换（PRD-00021）**：笔记旁浮窗与危险词粘贴页对「不能发」提供可编辑「替换成」+「替换」，不再出现「放弃」；空草稿不可替换并短提示；Enter 提交避开 IME 组字中误触。
- **出厂词库**：约 270 条「不能发」均带非空 `replacement`；单测断言零缺替换，并抽查命中带替换句。
- **规则镜像**：飞书《小红书平台违禁词》《实操总结违规词与违规点》落入 `docs/references/`，供维护对照；不进插件包。
- **词库扩充**：收录飞书备忘中的截流与自动化相关危险词。
- **脚手架**：升级至 2.8.0（备忘 / 收纳插件等内置流）。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.16.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.16.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.16.0`
- 改过 `assets/risk/factory-words.json` 后需重启操作台，运行时才会加载新出厂词
