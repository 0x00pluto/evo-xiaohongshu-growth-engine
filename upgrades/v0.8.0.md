# v0.8.0

相对 `v0.7.1`：换成 Dex Buddy SDK 1.0.0；写成笔记和刷图在任务开始前校验买断，购买与登录提示交给工作台。

## 变更

- **SDK**：模型助手改为 `lib/dex-buddy-sdk.js`（`SDK_VERSION` 1.0.0）；删除旧 `lib/dex-models.js`。生文、识图、生图仍走 `bindModels`。
- **买断闸门**：点「写成笔记」或刷图（生成 / 再抽 / 失败重试）时，本地校验通过后、任务开始前调用 `requireEntitlement`。未买断或未登录不进入「正在写 / 正在画」。
- **提示**：购买和登录只由工作台弹框；插件页面不贴「未开通」或错误码。买完或登完后点同一按钮再走。
- **独立运行**：本机 `node scripts/run-studio.js` 时闸门直接通过；缺 `DEX_BUDDY_API_KEY` 仍在真正请求时提示。
- 打开插件、逛历史、保存、复制、选图、显示文件不查买断。空业务句等本地错误仍先于买断。
- 清单 id 仍为 `app-dexbuddy-xiaohongshu-standard-editor`。重算提示词与学习图册本期不加提前闸门。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.8.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.8.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.8.0`
