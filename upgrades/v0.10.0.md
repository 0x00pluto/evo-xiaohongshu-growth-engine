# v0.10.0

相对 `v0.9.0`：一篇七档生图比例；笔记页工具卡胶囊化；生图同 key 重放；Dex Buddy SDK 升至 1.0.2。

## 变更

- **一篇一个比例**：七档可选；未点选跟图册样图归档档；点选后整篇锁定。学图按样图像素归档；发模型前程序覆盖画幅句。预览与缩略固定 3:4 占位 + contain。
- **笔记页工具卡**：比例 / 图册 / 提示词 / 参考图改为横向胶囊浮层；成稿顶栏可「写新的一篇」。
- **图库排序**：用户图册在前、出厂模板在后；卡面 3:4 + contain。
- **生图幂等**：发请求前落盘 `idempotencyKey`；网络失败后同 key 再调取回原图、不重复扣费；「再抽」或 `OUTPUT_EXPIRED` 才换 `gen-{n}`。
- **策划必填槽**：`copySchema` 未标可空的字段须填可上图文案；缺字段时有限重试（外刊等册的中文正文段勿留空）。
- **SDK**：`lib/dex-buddy-sdk.js` 升至 1.0.2（有参考图时默认 signed / `fileUrls`）。
- **PRD-00011**：一篇生图比例已验收关闭。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.10.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.10.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.10.0`
- 本机 `runtime/albums/` 里用户图册的 `copySchema` 若仍把 `bodyCn` 标成可空，可按本版策划约定自行收紧；该目录不入库
