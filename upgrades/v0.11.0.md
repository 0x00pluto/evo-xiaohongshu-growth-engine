# v0.11.0

相对 `v0.10.2`：资料库可学对标笔记、粘贴建风格/我们的图，落地产品资料库，并把操作台可见用词统一成运营人话。

## 变更

- **对标笔记进料**：资料库粘贴小红书链接，正文进对标文案、封面/后面的图进风格；静默注册 Native Host；链接身份与 cache 优先取料、双向溯源。
- **虚线上传**：新建风格与我们的图先出上传框，支持拖入、粘贴或点选本机图，再走学草稿 / 写图片用法。
- **产品资料库**：本机库 + 写笔记「加一条」可卡墙选库或写新；篇内去重、满 5 隐藏加号。
- **运营用词（PRD-00015）**：写笔记 / 风格 / 我们的图 / 对标文案 / 产品资料 / 画面内容 / 怎么画 / 图片用法等统一；删说明书灰字与人设目的组合说明；模型提示词与桥字段不动。
- **文档与验收**：同步 DESIGN / one-post-studio / FAQ；相关 PRD 工程验收关闭。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.11.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.11.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.11.0`
- 对标笔记取料需本机 Chrome 已登录小红书，且扩展已允许 Dex Buddy 连接；Host 由操作台/插件加载时静默写入
