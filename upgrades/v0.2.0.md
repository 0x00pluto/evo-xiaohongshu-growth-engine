# v0.2.0

相对 `v0.1.0`：图文提示词改为图册驱动，笔记页可选风格重算；配图仍按张生成。

## 更新说明

### 新增

- 图册目录 `albums/`：每册 `json` + 绘图题词 + `copy-sample`；ID 形如 `000001.magazine.dazibao`；同 kind 加册只加文件。
- 五本样图 `samples/<id>.jpg`，仅给人看 / Feed 预览，不喂文案或生图模型。
- 笔记页「图册风格」信息流与详情浮层；可「按此风格重算提示词」，文案不动。
- 画面步写入硬数字 `sceneCount`；条数不符自动再调一轮纠偏。
- 提示词目录改为英文路径：`article/`、`lines/`、`scenes.md`、`albums/`、`tone.md`。
- 本机操作台监听 `src/studio/static`，改页面后自动刷新。
- 补上封面类型、Cal 配色、整套图等 PRD；后端接入 `pnpm check:types`。

### 优化

- 操作台壳层与写笔记页走 Cal 色板；控件仍用 daisyUI 语义色。
- 首轮写成笔记随机抽册；旧稿短名 look 按 `legacyIds` 映射到新 ID。
- 每一张单独生成 / 再抽；历史版本可切换选用，不覆盖旧图。

### 修复

- 所选整套张数与模型返回画面条数不一致时整轮失败（如应为 2 却返回 6）。

### 破坏性变更

- 删除旧 `cover/`、`sets/` 提示词树；封面钩子与系列拆法改为图册 + `lines` / `scenes` 流程。
- 生图必须指明封面或某一张配图序号，不再一轮生成全部。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.2.0 https://github.com/0x00pluto/evo-xiaohongshu-growth-engine.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.2.0`（不含 v）
- 打开更早时期的稿时，若提示词或 look 对不上，回到「要发什么」再「写成笔记」，或按新风格重算提示词后再按张生图。
