# v0.2.0

相对 `v0.1.0`：封面从一条无字提示词改成按类型出钩子，配图改为一次生成一张。

## 更新说明

### 新增

- 封面提示词拆成三步：句子模块写出封面那句话，模型只在故事句（`story`）和对比（`compare`）里选一种，再套用该类型的画面和文字规则。选不中允许列表时，这一步失败，不生图。
- 素人号语气和大字规则只装填进选中的类型，不单独请求模型。主标题约占画面宽度的九成，文字区约占四成五。
- 配图页每一张都能改提示词。没有提示词时不能抽；已经生成过的可以再抽这一张。
- 本机操作台会监听 `src/studio/static`。改 HTML、JS 或 CSS 后，已打开的页面自动刷新。改 `src/one-post` 或启动脚本仍需重新运行命令。
- 补上封面类型 PRD（`prd-00002`）和操作台 Cal 配色 PRD（`prd-00003`）。

### 优化

- 操作台壳层、写笔记、历史共用 Cal 色板：主按钮近黑、白字，页面底为白，浅灰面和分割线跟色板走。控件仍用 daisyUI 语义色。
- 成稿只出标题、正文和话题。封面那句话由封面流程写入，并画进封面提示词。
- 已有稿的封面规则对不上这一版大字规则时，打开后标成待重算，已有图片先留着。

### 破坏性变更

- 删除单文件 `assets/prompts/one-post/cover.md`。封面提示词改为 `assets/prompts/one-post/cover/` 下的分文件。
- 生图必须指明封面或某一张配图的序号，不再一轮生成全部。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.2.0 https://github.com/0x00pluto/evo-xiaohongshu-growth-engine.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.2.0`（不含 v）
- 打开 v0.1.0 时期的稿时，画面可能标成待重算。先点「让画面跟上」，再按张生成。
