# v0.15.1

相对 `v0.15.0`：画面内容全空后再画这张会先定画面；拒绝路径不再把已有全文抹空。

## 变更

- **空全文再画（PRD-00020 / 飞书 20261117_0022）**：封面与配图全文都空时，`basis` 单独留着不再挡定画面；换风格或同风格再点画这张都会先定画面再出当前张。
- **拒绝不落盘**：同风格下仅当前张为空仍拒绝；拒绝前不写空可改段，其它张全文保持点击前内容。
- **空可改段嵌回**：没有第 11 槽的非空全文遇空可改段时原文保留，避免先被抹成空。
- **提示文案**：对人可见句改为「画面内容」；去掉「还没有这一张的提示词」。

- clone / 切换到本 tag：`git clone --branch v0.15.1 <origin>`
