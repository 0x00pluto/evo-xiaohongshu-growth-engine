# v0.13.0

相对 `v0.12.2`：对标笔记可反复学；资料库末尾卡墙与详情浮层；按 noteId 缓存比较写回原柜子（PRD-00017）。

## 变更

- **对标笔记 Tab**：资料库末尾卡墙（封面 / 标题 / 学习时间）；点卡开左图右文浮层；改学法跳转风格 / 对标文案原柜；删除级联名下图册与对标文案。
- **反复学**：同一 noteId 再贴链接或浮层「重新学」；成功取料后 30 分钟按 noteId 复用缓存；图 MD5 / 文案哈希比较；没变 toast「这篇没变」；变了写回原 `albumId` / `articleSampleId`；缺指纹可补录。
- **取料稳健**：空壳取料不覆盖可学缓存；有 noteId 时取料与入库用无 `xsec_token` 的规范 explore 链，降低风控触发。
- **学图可见**：从对标笔记学图时切到对标笔记 Tab；扫图 loading 与风格草稿为全局浮层，不打断「风格」页浏览。
- **详情链接**：文案显示规范链；仅当库中留有带 `xsec_token` 的原粘贴串时可点开；否则纯展示。
- **PRD**：`prd-00017` 工程验收 accepted；飞书需求 `20261110_0012` 已回填已完成。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.13.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.13.0`（不含 v）

- 已学过的脏 `sourceUrl`（带 token）会在读库时规范写回；点击打开依赖历史 `inputUrls` 中的带 token 粘贴串
