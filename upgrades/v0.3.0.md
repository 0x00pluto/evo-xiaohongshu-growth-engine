# v0.3.0

相对 `v0.2.0`：资料库图库管理（学习写入 / 删除）；新 kind 通用槽按题词自动装填；用户自加图册只留本机。

## 变更

- 左栏「资料库」壳 + Tab「图库」：卡片墙浏览、只读详情（无重算）、新建下拉交参考图学习成草稿后确认写入；自加可删、出厂不可删。
- 识图学习独立提示 `learn-album/system.md`；视觉模型缺省 `deepseek-flash`（可用 `DEEPSEEK_VISION_MODEL`）；用户图册序号自 `100000` 起。
- 新 kind 通用槽：按题词 `{{占位符}}` 与策划字段（含数组 → `*Block`）自动装填，学习产物不被「没有装填」拦住。
- 用户序号 ≥ `100000` 的 `albums/` / `samples/` 四件套 `.gitignore`，不随发版推给所有人。
- PRD-00005 工程验收关闭。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.3.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.3.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.3.0`
- 本机已有的用户图册仍在本地目录，不会出现在本 tag 的仓库树里
