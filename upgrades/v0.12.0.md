# v0.12.0

相对 `v0.11.0`：生图安全探针与 flagged 风格分流；操作台错误/成功反馈统一成带图标 toast。

## 变更

- **学风格探针**：入库前短提示试探；踩线则 `flagged` 落盘、资料库可见红盾，但不进写笔记风格选择；历史无字段仍当可选用。
- **CONTENT_FLAGGED**：宿主提示换画面说明或样图 / 我们的图；不清「取回」语义；说法对照库默认空 `rules`，机制保留。
- **历史绿盾**：非 flagged 风格在资料库显示通过态盾标。
- **标准 Toast**：错误红圆感叹号、成功绿圆对勾；顶部落入 / 上滑淡出；写笔记 / 资料库 / 历史 / 壳层共用 `lib/studio-toast.js`；去掉页顶与弹层内赤裸红字。
- **文档**：`DESIGN.md`、`image-prompt-safety` 工作流与索引同步。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.12.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.12.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.12.0`
- 已有 flagged 风格不会自动删；写笔记侧不再展示它们。需要时在资料库处理或换样图重学
