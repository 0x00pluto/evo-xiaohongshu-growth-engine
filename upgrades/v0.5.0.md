# v0.5.0

相对 `v0.4.0`：上传参考进生图与资料库；操作台侧栏可收起；学图册用扫图等待；插件设置保存后下一轮再生效。

## 变更

- **上传参考**：资料库「上传参考」Tab；篇内可囤多张、每槽最多勾 9 张进生图；可识图起草用法句、存进库；与图册、`runtime/image-refs/` 分工。
- **操作台侧栏**：菜单 Lucide 图标；大屏可收到只剩图标（状态记本机）；未上线菜单项不再展示「还没做」。
- **学图册等待**：居中 `image-scan` Lottie + 四段智能学习轮播文案；整层 `x-if` 挂载，默认 SVG 渲染。
- **生图**：可选 `sunburst` 模型地址（默认仍为 `flare`）；出厂参考角色补 `prior`（成稿底图 / 改图基础）。
- **学图约束**：保留实拍感并约束可空用语等提示词调整。
- **插件**：设置保存后下一轮再读配置，避免当轮读到旧值。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.5.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.5.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.5.0`
