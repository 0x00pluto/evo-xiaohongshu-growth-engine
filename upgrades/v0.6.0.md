# v0.6.0

相对 `v0.5.1`：成稿改人设×目的双轴与范文库；「以前的笔记」改成竖卡墙与小红书式详情浮层。

## 变更

- **成稿**：人设与目的分轴单选；提示词拆成 article-voices / article-types；材料页组合灰字与贴底「写成笔记」。
- **范文库**：资料库「范文」Tab；账号级 `runtime/materials/article-samples/`；写稿可从库挑或新建到库。
- **以前的笔记**：约 8 列 3:4 竖卡墙；点卡左图右文浮层（可翻图、复制 toast、编辑进笔记页）；页头与写一篇笔记 / 资料库同档。
- **接口**：`previewPostCover` / `previewHistoryPost` 按篇读图与详情，不切换当前稿；`listPosts` 增加 `hasCover`。
- **文档**：DESIGN / one-post-studio / 人设目的分类原文与 PRD-00007 已同步。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.6.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.6.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.6.0`
- 范文库路径 `runtime/materials/article-samples/`，只留本机、不随本 tag 入库
- 旧稿 `articleType=素人` 打开时会迁成目的「涨粉」+ 人设「素人」
