# v0.4.0

相对 `v0.3.0`：题词结构 v2；用户图册入 `runtime/` 与参考图说明分层；策划入站与绘图装填按模板 / copySchema 驱动；资料库可改题词并吸色。

## 变更

- 题词去掉「系列统一规则」槽，主题绘画内容改为第 11 项；图册 JSON 增加 `promptSheetVersion`（当前为 `2`）。
- 用户自加图册落在 `runtime/albums/`（gitignore）；参考图说明分出厂 `image-refs.md` 与 `runtime/image-refs/` 合并。
- 绘图装填与策划入站不再按 kind 写死字段白名单：按题词 `{{占位符}}` 与 copySchema 字段走，同 kind 扩展字段（如外刊 kicker 等）不再被砍掉。
- 资料库：用户册可保存题词；行内 `#RRGGBB` 色块与十字准星吸色；未保存关闭用页内确认浮层（不用 `window.confirm`）。
- 接口增加 `updateAlbumPrompt`；Dex 调用前打平 Alpine 载荷等配套修复。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.4.0 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.4.0`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.4.0`
- **题词结构**：仅支持 v2。本机仍含「系列统一规则」或未标 `promptSheetVersion: 2` 的旧图册需按 v2 改题词或重新学习后再装填
- 用户图册与 `runtime/image-refs/` 仍只留本机，不随本 tag 入库
