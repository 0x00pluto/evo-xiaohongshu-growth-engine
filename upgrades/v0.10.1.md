# v0.10.1

相对 `v0.10.0`：自学图册文案区口号与出厂原句不完全一致时，生图不再被「绘图提示词缺了文案区」拦死。

## 变更

- **去掉文案区口号拦截**：五种版式（杂志 / 手帐 / 观点 / 知识卡 / 信息图）填完题词后，不再核对出厂固定口号；画面句、展示句也不再要求原样出现在成稿里。
- **仍拦空值与结构**：画面或上图文案为空、题词不是 v2 / 缺 11 槽，仍会提示。文案区写岔了可改题词再抽，不卡死刷新。
- **回归测试**：五种版式故意不用出厂口号时，`renderAlbumPrompt` 仍能渲染。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.10.1 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.10.1`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.10.1`
- 已落盘的用户图册题词不必改；装本版后直接刷图即可
