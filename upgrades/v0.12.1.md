# v0.12.1

相对 `v0.12.0`：同步 Dex Buddy 插件 SDK 1.0.4，并把对标笔记可重建缓存改写到宿主 `ctx.dirs.cache`；附带飞书需求池工作流文档。

## 变更

- **SDK**：`lib/dex-buddy-sdk.js` 升为接口层 `1.0.4`（新增 `navigate` 导出）。独立跑仍为 `STANDALONE_VERSION` `1.0.3`。本插件无 `configSchema`、不调用 `navigate`。
- **缓存目录**：对标笔记原始快照优先写 `ctx.dirs.cache/xhs-notes`；安装后落在 `plugin-runtime/.../cache`，不再写进 `plugin-data`。本地「加载本地目录」路径与仓库 `cache/` 一致。旧 `plugin-data` 快照不迁移，可重建。
- **文档**：[`docs/workflows/one-post-studio.md`](../docs/workflows/one-post-studio.md) 与索引摘要对齐母版；新增飞书需求转入 / 回填工作流与 PRD-00016。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.12.1 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.12.1`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.12.1`
- 本机独立跑须保留 `lib/dex-buddy-standalone.js`；只上工作台时仍走宿主，不读本机 Key
