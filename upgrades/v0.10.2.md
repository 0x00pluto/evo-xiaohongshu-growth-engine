# v0.10.2

相对 `v0.10.1`：同步 Dex Buddy 插件 SDK 1.0.3（接口层与独立跑拆分），并更新本机挂载说明。

## 变更

- **SDK**：`lib/dex-buddy-sdk.js` 升为接口层 `1.0.3`；新增 `lib/dex-buddy-standalone.js`（`STANDALONE_VERSION` 1.0.3）。工作台仍走宿主；本机 `run-studio` 无宿主时懒加载 standalone。
- **开发挂载**：打包版 Dex Buddy 优先用插件页「加载本地目录」；`config.dev.json` / 软链仅给未打包维护者。
- **文档**：[`docs/workflows/one-post-studio.md`](../docs/workflows/one-post-studio.md) 与索引摘要已对齐母版约定。

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.10.2 <origin>`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.10.2`（不含 v）
- `plugin.manifest.json` 的 `version` 须同为 `0.10.2`
- 本机独立跑须保留 `lib/dex-buddy-standalone.js`；只上工作台时仍走宿主，不读本机 Key
