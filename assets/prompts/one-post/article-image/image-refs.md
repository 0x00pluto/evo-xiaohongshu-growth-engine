# 生图参考图说明（出厂）

出厂只放跨用户通用的角色。课程图、软件截图、硬件实物等场景说明放在
`runtime/image-refs/<pack-id>.md`，由程序与本文件按 `## role` 合并（同名以用户包为准）。

程序按实际上传顺序拼「第 N 张是…」；未出现的角色不要写入提示词。
正文不含「第 N 张」前缀，由代码按 `input_images` 下标补上。

## template

版式模板参考图，不是成稿。锁定底色、配色关系、字体气质、装饰种类与位置、留白与文字块位置。主文案必须使用题词里的中文文案，不要照抄模板原句。不要因模板新增题词未写明的插画或装饰。

## logo

品牌标识参考图。标识造型、比例与清晰度以本图为准；不要改绘成别的标志。

## prior

成稿底图（改图 / 修改基础）。只按上文已写出的变更改，未写的以本图为准，不要整图重绘。
