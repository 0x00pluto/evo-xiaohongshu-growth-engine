以下为「仅示例」：示范如何抽到本册卡片上下 layout。字段形状与抽取思路可参考；新稿必须按当前标题与正文重抽，禁止照抄示例文案。

## 抽取步骤

1. mainTitle：上方超大短句，须上图且醒目。
2. point：底部要点，一句可执行的收束或方法。
3. 多张时主标题彼此不同；不要写画面与配色。

## 完整 JSON 示例（勿照抄到新稿）

```json
{
  "frames": [
    { "mainTitle": "先装命令", "point": "再装插件，顺序反了会一直失败。" },
    { "mainTitle": "看报错那一行", "point": "缺的是系统能力，不是插件本身。" }
  ]
}
```
