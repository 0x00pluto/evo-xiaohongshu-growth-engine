以下为「仅示例」：示范如何抽到本册手帐便签式 layout。字段形状与抽取思路可参考；新稿必须按当前标题与正文重抽，禁止照抄示例文案。

## 抽取步骤

1. line：一句须准确上图的主笔记，像随手记下的判断。
2. note：可选短旁注（适合马克笔圈画旁）；没有则写空字符串 ""。
3. 不要写画面、配色、字号；多张时主句彼此不同。

## 完整 JSON 示例（勿照抄到新稿）

```json
{
  "frames": [
    { "line": "先把命令装进系统，再谈插件。", "note": "圈一下：PATH" },
    { "line": "装不上往往不是插件坏了。", "note": "" }
  ]
}
```
