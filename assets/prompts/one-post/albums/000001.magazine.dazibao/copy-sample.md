以下为「仅示例」：示范如何抽到本册大字报一行 layout。字段形状与抽取思路可参考；新稿必须按当前标题与正文重抽，禁止照抄示例文案。

## 抽取步骤

1. 通读标题与正文，抓住这一张要喊出的核心观点（封面是总，配图是分拍或收束）。
2. line：写成一句须准确上图的中文短句，口语、有判断，不要空泛口号。
3. 不要写画面、配色、字号；那些由本册图册模板负责。
4. 多张时各句彼此不同；最后一张不要照抄正文最后一句。

## 完整 JSON 示例（勿照抄到新稿）

单张封面时 frames 长度为 1；多张时按槽位各加一项。

```json
{
  "frames": [
    { "line": "不是插件坏了，是系统里没有这条命令。" },
    { "line": "两个插件都卡在这条命令上，安装没有完成。" }
  ]
}
```
