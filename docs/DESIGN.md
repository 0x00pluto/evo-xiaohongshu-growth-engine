# 视觉事实源

改外观前先读本文件。竖切顺序与红线在 [`docs/mvp-map.md`](./mvp-map.md)，不在这里重复。配色范围以 [`specs/prds/prd-00003-studio-cal-palette.md`](../specs/prds/prd-00003-studio-cal-palette.md) 为准。

## 页侧

- 一份 HTML。状态用 Alpine。需要控件时用 daisyUI 5 浅色。
- 页面底保持白。主按钮是近黑，不是蓝，也不是主题默认紫。
- 色值只用下面这组 daisyUI 语义变量。组件里不手写另一套颜色。
- 圆角和按钮尺寸跟随 daisyUI 5 浅色主题的默认控件，不另写一套。
- 图标用 Iconify Web Component + Lucide（`lucide:`），壳层加载 `iconify-icon`；不手画产品图标、不叠第二套图标库。
- 长等待（`job.running`）用 Lottie 浮层盖在「要发什么」表单或「这篇笔记」浅灰工具卡上（CDN `lottie-player` + `animations/job-running.json`），浮层下用 `stepText` 说明进度；不用顶栏「进行中：…」一行。小图右下角刷图转圈保留。
- 不上构建链，不上 Next.js，不上 htmx。读写走 JSON。
- Dex Buddy 把插件页面开在隔离窗口里。按钮走 `window.dex.call`。

## 配色

颜色来自 Cal.com 的色板，落到 daisyUI 的语义变量上。`data-theme="light"` 在壳层覆盖一次，写笔记和历史跟着变。

| 语义变量 | 色值 | 用途 |
|----------|------|------|
| `--color-primary` | `#111111` | 主按钮底 |
| `--color-primary-content` | `#ffffff` | 主按钮上的字 |
| `--color-base-100` | `#ffffff` | 页面底 |
| `--color-base-200` | `#f5f5f5` | 浅灰面 |
| `--color-base-300` | `#e5e7eb` | 边框与分割线 |
| `--color-base-content` | `#111111` | 默认文字 |
| `--color-error` | `#ef4444` | 错误 |
| `--color-error-content` | `#ffffff` | 错误底上的字 |
| `--color-success` | `#10b981` | 成功 |
| `--color-success-content` | `#ffffff` | 成功底上的字 |
| `--color-warning` | `#f59e0b` | 警告 |
| `--color-warning-content` | `#111111` | 警告底上的字 |
| `--color-accent` | `#3b82f6` | 点缀。不用于主按钮 |
| `--color-accent-content` | `#ffffff` | 点缀底上的字 |

Cal 的正文灰 `#374151` 本期不单独做。默认文字用 `#111111`。

## 排版

操作台现在的页面骨架。新页面沿用这一套，不另起间距、栏宽或卡片角色。落地在 `src/studio/static/index.html` 和 `src/studio/static/pages/note.html`。

### 壳

整页 `h-dvh`，中间区域滚动，底栏不跟着滚。

- 左边侧栏：菜单项用 Lucide（`iconify-icon` + `lucide:`），文案左侧一颗图标。大屏标题右侧可收起，收起后栏宽约 `4.5rem`、只留图标（悬停 `tooltip` 出名称）；窄屏仍用抽屉，图标与文字都在。未完成项不出现在侧栏（数据可留在 `shell.js` 的 `menu`）。收起状态记在 `localStorage` 键 `xhs-studio-nav-collapsed`。
- 顶上是标题行：左边页题 `text-xl font-medium`，行高 `px-4 py-3 lg:px-6`，右边次要动作用 `btn-sm`。写一篇笔记、以前的笔记、资料库共用这一档，不另起字号或内边距。
- 写一篇笔记：标题下面是居中的两步条（要发什么、这篇笔记）。底是浅灰，上下有分割线。
- 主操作放在最底一条，居中一颗近黑按钮。这一条固定在视口底部。

### 间距

块与块用 `gap-4`，卡片内边距用 `p-4`，卡片内部的小组用 `gap-3`。左右两栏不要用网格跨行去撑高。一边变高时，另一边上下的缝保持这个固定间距，不要被拉宽。

### 要发什么

一条居中窄栏，`max-w-2xl`，块间距 `gap-3`。自上而下：人设与目的（同一行两列；标签旁帮助）→ 组合灰字（身份/语气/目标，跟人设目的）→ 这篇想讲什么（标签+灰 hint+输入贴在一起）→ 参考资料（文档芯片，最多 5）→ 范文（`范文` 同行灰字说明；空：从库挑/新建；已选默认收起，展开只读预览，仅清除/换一篇）→ 封面张数。「写成笔记」贴底固定条（同「复制这篇」），业务一句为空时禁用。

### 这篇笔记

宽栏 `max-w-5xl`。大屏左边一列、右边 `20rem`，两列顶对齐。

- 左边先是浅灰工具卡（`bg-base-200`），自上而下：`图片 n/m`（右侧「显示文件」，仅当前张已生成时）+ 小图条（每张右下角图标刷图）与历史版本 → 「图册风格」→ 「这张的提示词」（默认收起）→ 「上传参考图」标题旁 `勾选数/9`（相对**当前张**；篇内可囤最多 48 张）；方块用 `auto-fill` 网格按容器宽度换行，末尾虚线 `+` 弹出「从库挑 / 上传」（池未满 48 可加）；点方块勾到**当前张**（每槽最多 9；默认新上传勾全槽，已满 9 的槽跳过）；左上深底白字加粗序号、选中时右下 `lucide:check` 绿勾；悬停时右上出 `lucide:pencil`，并在方块**上方**弹出预览卡（上大图、下用法）。列表不展示用法长句作标题。
- 下面是白底描边的文案卡。标题和正文直接改，不套输入框。话题写在正文末尾，和正文算在一起。
- 两张卡的上下间距就是上面的 `gap-4`，提示词展开或收起都不变。

字数按小红书计：半角（空格、英文字母、数字、半角符号）两个算一个字，全角和汉字算一个字，半角个数落单时向上取整。标题超过 20 字、正文超过 1000 字时，计数用错误色，文字仍留着，不截断；成稿与重算提示词不因标题超长拦截，由用户自删。正文框跟着全文增高，框内不出现滚动条。全文比一屏高时，滚的是中间那一层。

### 手机

右边预览的宽度跟「笔记预览 / 封面预览」那一排一样，铺满这 `20rem`。高度用 `aspect-[9/19.5]`（约 iPhone 竖屏比例）由宽度推出，约 `43.33rem`；矮视口时整页滚动，不压扁手机框。框底的操作条仍在框内。

笔记预览和封面预览共用这一只框，切换只换里面。框内才允许小红书红 `#FF2442`。封面的顶栏和底栏按图片自身比例缩放，不拉变形。

### 以前的笔记

独立页壳：顶栏与写一篇笔记同档（左「以前的笔记」、右「写新的一篇」`btn-primary btn-sm`）。主区是竖卡墙：`aspect-[3/4]` 封面（无封面时区内正文缩略），封面下标题两行与创建时间；列数 `grid-cols-3 sm:4 md:6 xl:8`，`gap-2`。卡片悬停右下角可复制。点卡打开小红书式详情浮层（不直接进编辑）：左选用封面与配图可翻（箭头、底点、`n/m`），右栏标题与时间下为可滚正文（`overscroll-contain`，滚轮不透传到卡墙），右下动作栏「复制」+「编辑」（近黑主按钮，无插件蓝钮）；「编辑」才进写一篇笔记并打开该篇。封面缩略与详情图均按篇读，不切换当前稿。

### 资料库

左栏「资料库」是独立页壳：顶栏标题「资料库」（与写一篇笔记同档 `text-xl`），下面一行资源 Tab（「图库」「上传参考」「范文」）。壳只管 Tab/`activeTab`；具体资源各自成模块，挂在对应 panel 里。

壳顶栏：左「资料库」、右「新建」下拉（灰字「创建新内容」，三项：「图库」「上传参考」「范文」；点「图库」交参考图学习；点「上传参考」切到对应 Tab、选本机图，浮层写用法句并可「识图起草」，确认后直写库；点「范文」切到范文 Tab 并打开新建浮层；笔记「存进库」仍可用）；其下是资源 Tab，无第二道操作顶栏。「图库」Tab 主区是图册竖卡墙（窄屏 3 列、大屏 6 列、略紧凑，节奏与笔记页「图册风格」一致；主区可纵向滚动）。学图册等待用居中浮层（`animations/image-scan.json` Lottie + 下方四段轮播文案：从左到右显现、轻脉冲前进、快消；不用顶栏进度条或「请稍等」一行）。详情与学习草稿浮层左样图右说明与题词，无重算按钮。详情题词区上方灰字标「题词结构 v{n}」（来自 JSON `promptSheetVersion`）。题词为单一白底 `contenteditable` 副文本框：可直接改字，`#RRGGBB` 后嵌不可编辑色块可吸色；无「编辑全文」切换。吸色用放大镜十字准星取样（无自绘吸管图标）。未保存关闭与删除均用页内确认浮层，不用 `window.confirm`（插件里常弹不出）。落盘仍是纯文本，不存 HTML。出厂五本详情只读。空列表时浅灰卡里说明并给出「新建」。用户自加图册落在 `runtime/albums/<id>/` 一册一夹（与成稿 `output/` 分工），只留本机、不入库。「上传参考」Tab 主区是方块网格（同列数节奏，只图不叠用法长句）；空列表浅灰卡说明并可「新建」；点卡打开左图右用法浮层，标题固定「上传参考」；可二次确认后删除库内条目。库路径 `runtime/materials/upload-refs/`，与图册、`runtime/image-refs/` 分开。「范文」Tab 主区与图库同节奏（窄屏 3 列、大屏 6 列）：`aspect-[3/4]` 竖卡，正文缩略保留换行，底叠渐变标题；空列表浅灰卡说明并可「新建」；新建/改写为单框粘贴（第一行标题、其余正文）；点开可改可删；删除用页内确认。库路径 `runtime/materials/article-samples/<id>/meta.json`，与上传参考、图册样图目录分开。以后加其它资源类型：在壳的 `tabs` 加一项，新建 `pages/library/<type>.js`，HTML 加对应 panel；「新建」菜单按需加一项。

### 新页面

沿用这套壳、间距，以及浅灰工具卡 / 白底文案卡。需要主操作时，放底栏正中一颗主按钮。不另起一套颜色。

## 离开本事实源

操作台变成多路由产品，并且设计系统已经锁在 React，两件同时成立，才离开 HTML First。在那之前保持现在的页侧。
