# 视觉事实源

改外观前先读本文件。竖切顺序与红线在 [`docs/mvp-map.md`](./mvp-map.md)，不在这里重复。配色范围以 [`specs/prds/prd-00003-studio-cal-palette.md`](../specs/prds/prd-00003-studio-cal-palette.md) 为准。

## 页侧

- 一份 HTML。状态用 Alpine。需要控件时用 daisyUI 5 浅色。
- 页面底保持白。主按钮是近黑，不是蓝，也不是主题默认紫。
- 色值只用下面这组 daisyUI 语义变量。组件里不手写另一套颜色。
- 圆角和按钮尺寸跟随 daisyUI 5 浅色主题的默认控件，不另写一套。
- 图标用 Iconify Web Component + Lucide（`lucide:`），壳层加载 `iconify-icon`；不手画产品图标、不叠第二套图标库。
- 长等待（`job.running`）用 Lottie 浮层盖在「要发什么」表单或「这篇笔记」浅灰工具卡上（CDN `lottie-player` + `animations/job-running.json`），浮层下用 `stepText` 说明进度；不用顶栏「进行中：…」一行。点「写成笔记」立刻切到第二页现成骨架（空图槽、空标题正文、手机框），成稿未回也出这套卡，不留「笔记还在写」一行字。写文时浮层为「正在写这篇笔记」；刷新定画面为「正在定这一套图」；生图为「正在用{图册名}画封面」或「正在用{图册名}画第 N 张」（没有图册名则「正在画封面 / 正在画第 N 张」）。出图路径不出现「写这篇笔记」。小图右下角刷图转圈保留。
- 运营可读错误与短反馈统一用 daisyUI toast（`lib/studio-toast.js` 的 `createStudioToast`）：`toast toast-top toast-center` 内一层 `max-w-md` 白底阴影卡；错误左侧 `bg-error/15` 圆 + `lucide:circle-alert` 感叹号，成功左侧 `bg-success/15` 圆 + `lucide:circle-check` 绿对勾；入场约 200ms 下落淡入、离场约 150ms 上滑淡出（`motion-reduce:transition-none`）；约 2s 消失，长文案约 4s。禁止无图标纯字条、禁止页顶 / 弹层内赤裸 `text-error` 长句钉死。字数超限计数变红、删除 `btn-error`、风格安全盾 icon、资料库 flagged 色块状态条不算这类提示，可保留。
- 不上构建链，不上 Next.js，不上 htmx。读写走 JSON。
- Dex Buddy 把插件页面开在隔离窗口里。按钮走 `window.dex.call`。

## 配色

颜色来自 Cal.com 的色板，落到 daisyUI 的语义变量上。`data-theme="light"` 在壳层覆盖一次，写笔记和历史跟着变。

| 语义变量 | 色值 | 用途 |
|----------|------|------|
| `--color-primary` | `#111111` | 主按钮底 |
| `--color-primary-content` | `#ffffff` | 主按钮上的字 |
| `--color-base-100` | `#ffffff` | 页面底 |
| `--color-base-200` | `#f5f5f5` | 浅灰面 |
| `--color-base-300` | `#e5e7eb` | 边框与分割线 |
| `--color-base-content` | `#111111` | 默认文字 |
| `--color-error` | `#ef4444` | 错误 |
| `--color-error-content` | `#ffffff` | 错误底上的字 |
| `--color-success` | `#10b981` | 成功 |
| `--color-success-content` | `#ffffff` | 成功底上的字 |
| `--color-warning` | `#f59e0b` | 警告 |
| `--color-warning-content` | `#111111` | 警告底上的字 |
| `--color-accent` | `#3b82f6` | 点缀。不用于主按钮 |
| `--color-accent-content` | `#ffffff` | 点缀底上的字 |

Cal 的正文灰 `#374151` 本期不单独做。默认文字用 `#111111`。

## 排版

操作台现在的页面骨架。新页面沿用这一套，不另起间距、栏宽或卡片角色。落地在 `src/studio/static/index.html` 和 `src/studio/static/pages/note.html`。

### 壳

整页 `h-dvh`，中间区域滚动，底栏不跟着滚。

- 左边侧栏：菜单项用 Lucide（`iconify-icon` + `lucide:`），文案左侧一颗图标。大屏标题右侧可收起，收起后栏宽约 `4.5rem`、只留图标（悬停 `tooltip` 出名称）；窄屏仍用抽屉，图标与文字都在。未完成项不出现在侧栏（数据可留在 `shell.js` 的 `menu`）。收起状态记在 `localStorage` 键 `xhs-studio-nav-collapsed`。
- 顶上是标题行：左边页题 `text-xl font-medium`，行高 `px-4 py-3 lg:px-6`，右边次要动作用 `btn-sm`。写笔记、以前的笔记、资料库共用这一档，不另起字号或内边距。
- 写笔记：标题行右在「这篇笔记」步显示「写新的一篇」`btn-ghost btn-sm`（左）与「以前的笔记」同档（右）；材料步只留「以前的笔记」。标题下面是居中的两步条（要发什么、这篇笔记）。底是浅灰，上下有分割线。
- 主操作放在最底一条，居中一颗近黑按钮（材料步「写成笔记」、成稿步「复制这篇」）。这一条固定在视口底部；「写新的一篇」不进底栏、不做 primary，避免与「复制这篇」抢高潮。

### 间距

块与块用 `gap-4`，卡片内边距用 `p-4`，卡片内部的小组用 `gap-3`。左右两栏不要用网格跨行去撑高。一边变高时，另一边上下的缝保持这个固定间距，不要被拉宽。

### 要发什么

一条居中窄栏，`max-w-2xl`，块间距 `gap-3`。自上而下：人设与目的（同一行两列；无旁帮助、无组合灰字）→ 这篇想讲什么（标签+灰 hint+输入贴在一起）→ 产品资料（文档方块，最多 5，满额隐藏 `+`；点 `+`：库有可选则卡墙选库，底部「新建产品资料」写新；库空直接写新；篇内正文不重复；点方块只改这篇）→ 对标文案（无旁灰字说明；空：从库挑/新建；已选默认收起，展开只读预览，仅清除/换一篇）→ 笔记内图数量（步进器 0–9，不含封面）。「写成笔记」贴底固定条（同「复制这篇」），业务一句为空时禁用。

### 这篇笔记

宽栏 `max-w-5xl`。大屏左边一列、右边 `20rem`，两列顶对齐。

- 左边先是浅灰工具卡（`bg-base-200`），自上而下：`图片 n/m`（右侧「打开文件」常显可点，有图打开该文件、无图打开本篇文件夹）→ 小图条与历史版本（外框固定小红书通用 `3:4` 占位，图 `object-contain` 整图显示、比例不合则留白；换比例不撑高工具卡；无历史版本时收回该行；每张右下角图标刷图）→ 横向比例/风格/画面内容/我们的图胶囊（`lucide:ratio`、`lucide:palette`、`lucide:text`、`lucide:image`+`n/9`；`btn-sm` 描边；点开在按钮下方浮层，不撑高工具卡；四者互斥只开一个，点空白收起）→ 比例浮层七档网格（画幅示意 + 文字；一篇共用；未点过跟当前风格归档比例，点过后锁定）→ 风格浮层样图格（卡面固定 `3:4`，样图 contain；列表用户册在前、出厂模板在后；点卡即选中并收起，刷新才套到整套）→ 画面内容浮层通栏宽、编辑框加高（未套词时胶囊不可开）→ 我们的图浮层通栏宽（相对**当前张**勾选数/`9`；篇内最多 48 张；无说明书灰字）；方块用 `auto-fill` 网格按容器宽度换行，末尾虚线 `+` 弹出「从库挑 / 上传」（池未满 48 可加）；点方块勾到**当前张**（每槽最多 9；默认新上传勾全槽，已满 9 的槽跳过）；左上深底白字加粗序号、选中时右下 `lucide:check` 绿勾；悬停时右上出 `lucide:pencil`，并在方块**上方**弹出预览卡（上大图、下图片用法）。列表不展示图片用法长句作标题。
- 下面是白底描边的文案卡。标题和正文直接改，不套输入框。话题写在正文末尾，和正文算在一起。
- 两张卡的上下间距就是上面的 `gap-4`，画面内容展开或收起都不变。

字数按小红书计：半角（空格、英文字母、数字、半角符号）两个算一个字，全角和汉字算一个字，半角个数落单时向上取整。标题超过 20 字、正文超过 1000 字时，计数用错误色，文字仍留着，不截断；成稿与刷图不因标题超长拦截，由用户自删。正文框跟着全文增高，框内不出现滚动条。全文比一屏高时，滚的是中间那一层。

### 手机

右边预览的宽度跟「笔记预览 / 封面预览」那一排一样，铺满这 `20rem`。高度用 `aspect-[9/19.5]`（约 iPhone 竖屏比例）由宽度推出，约 `43.33rem`；矮视口时整页滚动，不压扁手机框。框底的操作条仍在框内。

笔记预览和封面预览共用这一只框，切换只换里面。框内才允许小红书红 `#FF2442`。笔记预览主图区域固定 `3:4`，图用 contain 整图显示（比例不合则留白；换比例不改主图区高度）。封面预览发现页假环境仍按 `3:4` 裁封面；有效比例不是 `3:4` 时加一行「发现页按 3:4 裁封面」。封面的顶栏和底栏按图片自身比例缩放，不拉变形。

### 以前的笔记

独立页壳：顶栏与写笔记同档（左「以前的笔记」、右「写新的一篇」`btn-primary btn-sm`）。主区是竖卡墙：`aspect-[3/4]` 封面（无封面时区内正文缩略），封面下标题两行与创建时间；列数 `grid-cols-3 sm:4 md:6 xl:8`，`gap-2`。卡片悬停右下角可复制。点卡打开小红书式详情浮层（不直接进编辑）：左选用封面与配图可翻（箭头、底点、`n/m`），右栏标题与时间下为可滚正文（`overscroll-contain`，滚轮不透传到卡墙），右下动作栏「打开文件」+「复制」+「编辑」（近黑主按钮，无插件蓝钮）；有图才可打开文件（按篇打开访达，不切换当前稿）；「编辑」才进写笔记并打开该篇。封面缩略与详情图均按篇读，不切换当前稿。

### 资料库

左栏「资料库」是独立页壳：顶栏标题「资料库」（与写笔记同档 `text-xl`），下面一行资源 Tab（「风格」「我们的图」「对标文案」「产品资料」「对标笔记」；末尾一项；默认仍「风格」）。壳只管 Tab/`activeTab`；具体资源各自成模块，挂在对应 panel 里。

壳顶栏：左「资料库」、右「新建」下拉（无「创建新内容」灰标题；五项：「风格」「我们的图」「对标文案」「产品资料」「对标笔记」；点「风格」或「我们的图」先出居中虚线上传框（拖入、Ctrl+V / ⌘V 粘贴、或点击从本机选一张 JPEG / PNG / WebP / BMP，≤8MB；JPEG 含 .jpg/.jpeg/.jpe/.jfif 大小写；无单独粘贴钮、打开时不读剪贴板）；风格合格后交学习成草稿；我们的图合格后切到对应 Tab、浮层写图片用法并可「自动识别」，确认后直写库；点「对标文案」切到对标文案 Tab 并打开新建浮层；点「产品资料」切到产品资料 Tab 并打开新建浮层；点「对标笔记」弹层先探测读取通道与扩展 ≥0.9.0（通过显示绿色「Chrome插件连接正常」，未通过禁用粘贴并给重试）；再粘贴 explore / xhslink，或从「对标笔记」浮层「重新学」预填；读取后勾选文案 / 封面 / 一张后面的图；已知笔记旁有文字徽标「没变 / 有更新 / 需确认 / 未学过」，「没变」锁定不可勾；全没变 toast「这篇没变」；变了的写回原图册 / 对标文案 id，缺指纹只补指纹；确认后链接写入 `runtime/materials/xhs-notes/`，正文进对标文案库，图走现有学图草稿；学完若有对标文案可「用这篇去写」；笔记「保存到资料库」仍可用）；其下是资源 Tab，无第二道操作顶栏。「风格」Tab 主区是风格卡墙（窄屏 3 列、大屏 6 列、略紧凑，节奏与笔记页「风格」一致；卡面固定 `aspect-[3/4]`，样图 contain；列表用户册在前、出厂模板在后；主区可纵向滚动）。学风格等待用居中浮层（`animations/image-scan.json` Lottie + 下方四段轮播人话：正在看这张图 / 在看配色和排版 / 在整理这套风格 / 马上出一套草稿；从左到右显现、轻脉冲前进、快消；不用顶栏进度条或「请稍等」一行）。详情与学习草稿浮层左样图右说明与「怎么画」，无重算按钮。不展示「题词结构 v{n}」。怎么画为单一白底 `contenteditable` 副文本框：可直接改字，`#RRGGBB` 后嵌不可编辑色块可吸色；无「编辑全文」切换。吸色用放大镜十字准星取样（无自绘吸管图标）。未保存关闭与删除均用页内确认浮层，不用 `window.confirm`（插件里常弹不出）。落盘仍是纯文本，不存 HTML。出厂五本详情只读。空列表浅灰卡只留「还没有风格。」等一句并给出「新建」。用户自加风格落在 `runtime/albums/<id>/` 一册一夹（与成稿 `output/` 分工），只留本机、不入库。「我们的图」Tab 主区是方块网格（同列数节奏，只图不叠图片用法长句）；空列表「还没有我们的图。」并可「新建」；点卡打开左图右图片用法浮层，标题固定「我们的图」；可二次确认后删除库内条目。库路径 `runtime/materials/upload-refs/`，与风格、`runtime/image-refs/` 分开。「对标文案」Tab 主区与风格同节奏（窄屏 3 列、大屏 6 列）：`aspect-[3/4]` 竖卡，正文缩略保留换行，底叠渐变标题；空列表「还没有对标文案。」并可「新建」；新建/改写为单框粘贴（第一行标题、其余正文）；点开可改可删；删除用页内确认。库路径 `runtime/materials/article-samples/<id>/meta.json`，与我们的图、风格样图目录分开。「产品资料」Tab 主区同对标文案节奏（窄屏 3 列、大屏 6 列、`aspect-[3/4]` 竖卡、底叠名称）；空列表「还没有产品资料。」并可「新建」；新建/改写为单框粘贴（第一行名称、其余正文）；点开可改可删；删除用页内确认。库路径 `runtime/materials/reference-docs/<id>/meta.json`，与对标文案、我们的图、风格分开。「对标笔记」Tab 主区对齐以前的笔记卡墙（窄屏 3 列、宽屏约 8 列、`aspect-[3/4]`）；空列表「还没有对标笔记。」并可「新建」；点卡开左图右文浮层（翻图、两行怎么画、「改这张的学法」/「改这篇文案」跳到风格或对标文案详情、底「重新学」「删除」；删除页内确认、级联名下图册与对标文案）。链接身份在 `runtime/materials/xhs-notes/<id>/meta.json`（含图文指纹）。以后加其它资源类型：在壳的 `tabs` 加一项，新建 `pages/library/<type>.js`，HTML 加对应 panel；「新建」菜单按需加一项。

### 新页面

沿用这套壳、间距，以及浅灰工具卡 / 白底文案卡。需要主操作时，放底栏正中一颗主按钮。不另起一套颜色。

## 离开本事实源

操作台变成多路由产品，并且设计系统已经锁在 React，两件同时成立，才离开 HTML First。在那之前保持现在的页侧。
