**风险等级：**

🔴 高风险：

涉及违法违规、虚假承诺、违规导流、无资质推广等，应删除或调整内容。

🟠 重点排查：

涉及效果承诺、绝对化表达、身份资质、行业监管等，应有依据并审核。

🟡 语境敏感：

单独使用不一定违规，但商业场景中建议谨慎表达。

# 一、全行业通用风险词库

## 01 绝对化及极限宣传词

**风险词汇：**

🔴 国家级、世界级、全球第一、中国第一、行业第一、全国第一、全网第一、第一品牌、唯一、首创、独家、顶级、最高级、最佳、最好、最强、最优、极品、极致、完美、绝对、无敌、NO.1、遥遥领先。

🟠 最受欢迎、人人都在用、销量冠军、行业标杆、天花板、顶配、巅峰、最值得、最推荐、首选、必买、必看、必选。

**✅ 建议替换：**

- 行业第一 → 专注于某一细分领域
- 顶级品质 → 注重品质与细节
- 最佳选择 → 一种值得了解的选择
- 唯一选择 → 具有自身特色的方案
- 完美体验 → 更贴合实际需求的体验
- 遥遥领先 → 在某些方面具有自身特点

**注意：**有些词在非商业语境中可能正常，但涉及广告宣传时，尤其是绝对化用语，需要严格排查。

## 02｜虚假宣传及效果承诺词

🔴 永久有效、百分百有效、100%成功、保证成功、绝对安全、零风险、稳赚不赔、包过、包录取、包移民、保证收益、无任何风险、保证获批。

🟠 轻松实现、快速见效、立竿见影、全面提升、彻底解决、一次解决、永久保持、人人适用、所有人都适合、无需任何条件。

**✅ 建议替换：**

- 保证成功 → 根据实际条件制定方案
- 100%有效 → 具体效果因实际情况而异
- 彻底解决 → 提供相应解决思路
- 快速见效 → 具体进度视实际情况而定
- 零风险 → 如实说明可能存在的风险
- 保证收益 → 客观介绍历史表现及相关风险

## 03｜诱导互动及账号行为词

🔴 在商业营销场景中，重点排查：

点赞、收藏、转发、评论、关注我、关注账号、私信我、私信领取、评论区扣1、评论区留言、主页联系、主页有联系方式、加微信、加V、微信同号、扫码咨询、添加好友、进群、点击链接、跳转第三方。

🟠 关注、经营、引流、获客、成交、变现、招商、代理、加盟、接单、咨询、领取资料、免费领取、名额有限。

✅ 建议替换：

- 关注 → 留意、观察、了解
- 经营 → 品牌日常、业务发展、日常工作
- 引流 → 内容传播、用户触达
- 获客 → 客户需求研究、用户触达
- 私信领取 → 通过平台允许的内容功能获取信息
- 加微信 → 删除站外联系方式引导
- 进群 → 删除站外社群导流表达
- 招商 → 品牌发展信息（前提是内容本身合规）

特别说明：不能通过拼音、谐音、符号、拆字、二维码等形式规避平台导流审核。

## 04｜联系方式及站外导流词

🔴 微信号、手机号、QQ号、电话号码、二维码、微信二维码、联系方式、邮箱、外部链接、第三方平台账号、社交媒体账号、加好友、扫码添加、主页留联系方式。

常见变体同样需要排查：

- V我、+V、VX、微我
- 主页有微、头像有微
- 加联系方式、看主页、其他平台见
- 通过其他平台联系、站外沟通

建议：商业获客使用平台允许的专业号及合规获客工具，不使用隐晦表达绕开审核。

## 05｜虚构身份及资质背书词

🔴 假冒医生、假冒律师、假冒专家、假冒教授、虚构机构、虚构认证、伪造证书、虚构合作案例、虚构客户评价、虚构服务经历。

🟠 权威专家、官方认证、国际认证、行业专家、资深导师、首席顾问、专业团队、官方指定、政府合作、战略合作伙伴。

✅ 建议替换：

- 权威专家 → 具备相关资质的专业人员（有事实依据）
- 官方认证 → 明确具体认证机构和认证内容
- 资深团队 → 客观介绍团队从业经历
- 成功案例 → 真实、获得授权且可核实的案例
- 政府合作 → 有真实合作关系及相应证明再使用

## 06｜封建迷信及不科学功效词

🔴 招财、转运、改运、旺财、旺事业、旺桃花、辟邪、化煞、消灾、改命、开运、保平安、催姻缘、转运消灾。

🟠 正能量磁场、能量提升、改善运势、旺夫、旺子、提升财运、改变命运。

✅ 建议：可以讨论文化、艺术、传统习俗和历史寓意，但不能把缺乏科学依据的功效当作商品或服务的真实效果宣传。

## 07｜恐吓、焦虑及负面营销词

🔴 不买就亏、再不做就晚了、错过后悔一辈子、必然失败、一定被淘汰、人生彻底毁了。

🟠 普通人没机会、阶层固化、财富危机、家庭危机、孩子输在起跑线、错过最佳时机、落后别人一大截。

✅ 建议替换：

- 孩子输在起跑线 → 不同成长阶段的教育需求
- 财富危机 → 家庭资产管理中的常见问题
- 错过最佳时机 → 不同阶段的选择与规划
- 一定失败 → 需要提前评估的潜在风险

## 08｜其他高风险表达

- 低俗、色情、性暗示及不文明用语
- 侮辱、歧视、贬低他人或第三方品牌
- 未经授权展示个人隐私
- 未经证实的新闻、数据和社会事件
- 虚构用户反馈、虚构交易记录
- 未经授权使用他人肖像、品牌商标和作品
- AI生成内容冒充真实人物、真实经历
- 使用谐音、英文缩写、符号掩盖违规内容

# 二、10大高净值行业专属风险词库

# 01 家庭教育与全球化规划

涵盖：国际教育、国际课程、留学申请、升学规划、家庭国际化规划等。

### A. 高风险词汇

🔴 保录取、包录取、百分百录取、保进名校、保证入学、保进藤校、保证拿到Offer、内部名额、内部招生、保过语言考试、保证高考提分、保证升学。

### B. 重点排查词汇

🟠 名校直通车、名校捷径、内部渠道、保底名校、快速提分、名师押题、名校资源、升学无忧、轻松留学、低分逆袭。

### C. 教育培训专属表达

🟠 提分神器、快速提分、满分课程、押题命中、考试包过、名师一对一、保过班、升学保证。

### ✅ 建议替换

- 保录取 → 申请规划与材料准备
- 包进名校 → 结合申请条件制定院校方案
- 内部渠道 → 院校公开招生信息
- 低分逆袭 → 不同学术背景下的申请策略
- 保证提分 → 学习方法与阶段性进度分析
- 名校直通 → 院校申请路径解析

### ✨ 特别注意

1. 不得虚构学校合作、招生关系和录取案例。
2. 不得承诺学校录取、考试成绩和奖学金结果。
3. 留学中介、教育培训及相关业务应核对经营范围、专业资质及平台行业准入要求。
4. 不得将普通服务包装成学校官方项目。

# 02 财富管理与家族传承

涵盖：全球资产配置、私人银行、保险规划、家族信托、家族办公室、财富传承、税务规划。

### A. 高风险词汇

🔴 保本保息、稳赚不赔、零风险投资、保证收益、固定高回报、100%盈利、稳赚、快速翻倍、内幕消息、内部配额、保收益、无风险套利、非法荐股。

### B. 重点排查词汇

🟠 财富自由、资产翻倍、财富增值、收益最大化、稳赚策略、财富密码、避税、零税负、绝对安全、资金安全保障、保证回报。

### C. 金融及保险专属表达

🟠 高收益理财、保本理财、稳赚基金、收益保证、保险收益承诺、快速回本、保证分红、无条件理赔、永久免税。

### ✅ 建议替换

- 稳赚不赔 → 介绍投资逻辑及风险因素
- 财富翻倍 → 长期资产配置思路
- 零风险 → 风险识别与风险管理
- 避税 → 合规税务规划
- 财富自由 → 家庭长期财务目标
- 收益最大化 → 综合评估风险与收益
- 保证分红 → 依据合同约定及实际情况说明

### ✨ 特别注意

1. 金融业务属于重点监管领域，相关营销需要依法取得相应许可及平台要求的资质。
2. 禁止非法荐股、投资跟单、收益承诺、虚构投资人设。

# 03 高端房产与品质居住

涵盖：豪宅、别墅、海外房产、高端室内设计、装修、高端家居、智能住宅。

### A. 高风险词汇

🔴 保证升值、稳赚不赔、保证回报、永久增值、零风险购房、包租、保证租金、百分百产权、永久产权（与实际权属不符时）、保证学区、内部房源（虚构时）。

### B. 重点排查词汇

🟠 房价必涨、投资稳赚、最佳地段、绝版房源、全城第一豪宅、稀缺资产、保值增值、稳赚投资、学区房保证、永久升值。

### C. 房产及装修专属表达

🟠 零甲醛、绝对环保、百分百无污染、终身质保、永不损坏、永久防水、零风险装修、百分百隔音。

### ✅ 建议替换

- 保证升值 → 区域历史价格及市场情况分析
- 稳赚投资 → 房产投资风险与成本分析
- 最佳地段 → 区位条件及周边配套介绍
- 绝版房源 → 介绍具体房源特点
- 零甲醛 → 依据检测报告说明甲醛指标
- 永久产权 → 依据实际产权及法律文件说明

### ✨ 特别注意

1. 房源信息、面积、产权、价格必须真实。
2. 不得虚构学区、交通、商业配套及未来规划。
3. 不得承诺房产升值、租金收益或投资回报。
4. 海外房产需特别核实当地法律、土地性质、产权年限及购房限制。
5. 装修和家居产品涉及环保、健康、性能时应有可靠检测依据。

# 04 医疗健康与养老

涵盖：高端医疗、国际医疗、私人健康管理、抗衰、医美、康养、高端养老。

### A. 高风险词汇

🔴 根治、治愈、包治、彻底康复、百分百有效、永不复发、逆转衰老、返老还童、永久年轻、无副作用、保证瘦身、保证增高、永久抗衰。

### B. 重点排查词汇

🟠 细胞修复、基因修复、排毒、抗衰老、逆龄、冻龄、年轻十岁、快速减脂、燃脂、提高免疫力、激活细胞、改善疾病、修复身体。

### C. 医美专属表达

🔴 无痛无创、永久定型、百分百安全、零恢复期、一次见效、永久祛皱、永久美白、绝对无风险。

🟠 童颜、逆龄、无痕、零创伤、快速恢复、效果立竿见影。

### D. 养老及健康管理表达

🟠 延长寿命、长寿秘诀、永不生病、疾病预防保证、完全康复、改善所有慢性病。

### ✅ 建议替换

- 根治 → 具体医疗方案及适用条件
- 逆转衰老 → 年龄相关健康管理知识
- 永久年轻 → 日常健康管理与生活方式
- 快速减脂 → 科学体重管理方法
- 无副作用 → 依据产品说明及专业评估介绍风险
- 一次见效 → 实际效果因人而异

### ✨ 特别注意

1. 医疗、药品、医疗器械、医美、保健食品均属于高监管行业。
2. 不得虚构医生身份、医院资质、诊疗经历和治疗效果。
3. 不得把普通食品、普通化妆品宣传成具有疾病治疗功效的产品。
4. 医疗医药类蒲公英合作内容存在专门管控要求，不能简单按照普通消费品广告处理。
5. 健康科普不能变相为具体医疗项目、药品或医疗器械进行违规推广。

# 05 高端旅游与旅行体验

涵盖：私人定制旅游、国际旅行、精品酒店、私人旅行服务、游艇旅行、定制旅行。

### A. 高风险词汇

🔴 保证出签、百分百过签、包过签证、保证入境、免签保证、零风险出行、保证航班、保证升舱、保证入住。

### B. 重点排查词汇

🟠 全网最低价、全球最美、世界第一酒店、绝对安全、顶级体验、独家资源、内部渠道、免排队、保证成行、百分百成团。

### C. 旅行服务专属表达

🟠 VIP通道、特殊通道、内部票、内部房、特殊签证渠道、保证入境、免签包过。

### ✅ 建议替换

- 保证出签 → 根据申请条件整理签证材料
- 保证入住 → 依据酒店订单确认入住安排
- 全球最美 → 介绍当地景观特色
- 独家资源 → 介绍实际合作资源
- 绝对安全 → 介绍安全保障措施与风险提示
- 保证成行 → 依据实际预订及出行条件说明

### ✨ 特别注意

1. 不得虚构酒店、航空公司及当地机构合作关系。
2. 不得承诺签证、入境和审批结果。
3. 旅游产品价格、行程、住宿及服务标准必须真实。
4. 不得夸大所谓特殊渠道、内部渠道和特权资源。
5. 涉及旅行社、签证服务及境外业务，需核对相应资质。

# 06 高端消费与艺术收藏

涵盖：珠宝、奢侈品、艺术收藏、艺术品鉴赏、精品消费、收藏品服务。

### A. 高风险词汇

🔴 永不掉色、永久保值、百分百纯金（没有对应检测依据时）、绝对纯天然、完美无瑕、稳赚不赔、保证升值、保值率第一、永久增值、招财、转运、旺财、辟邪。

### B. 重点排查词汇

🟠 顶级珠宝、世界级工艺、顶级收藏、稀世珍品、收藏级、传世之作、投资价值极高、升值空间巨大、极品宝石、绝版珍藏。

### C. 珠宝专属风险词汇

🟠 永不褪色、永久防水、绝对不掉钻、百分百天然、无瑕疵、纯天然无优化、永久保值。

注意：足金999、18K金、天然钻石等具体材质名称本身不是违禁词，但必须与实际商品、检测报告和相关证明一致。

### D. 艺术收藏专属风险词汇

🔴 保证升值、稳赚不赔、百分百真迹、绝对保真、保证拍卖成交、保证回购、保证增值。

🟠 孤品、唯一真迹、国家级珍藏、绝世珍品、投资回报率、未来升值空间。

### ✅ 建议替换

- 保证升值 → 介绍艺术品的历史、市场与收藏背景
- 永久保值 → 介绍材质、工艺及收藏特点
- 顶级珠宝 → 品质珠宝、设计珠宝、工艺珠宝
- 绝对纯天然 → 依据检测结果客观描述
- 招财转运 → 介绍传统文化中的艺术寓意
- 百分百真迹 → 依据可靠鉴定资料说明作品来源

### ✨ 特别注意

1. 珠宝材质、贵金属成色、宝石来源必须真实。
2. 不得虚构鉴定证书、收藏经历、拍卖价格和成交记录。

# 三、10大行业共同适用的发布前检查

## 01 标题检查

- 是否存在极限词？
- 是否存在夸张承诺？
- 是否制造不必要的焦虑？
- 标题是否与正文真实内容一致？

## 02 正文检查

- 是否虚构经历、客户、案例或数据？
- 是否涉及保证效果或保证收益？
- 是否存在未经证明的权威背书？
- 是否涉及行业资质要求？
- 是否存在违规互动或站外导流？

## 03 图片检查

- 封面文字是否包含敏感表达？
- 图片中的证书、资质是否真实？
- 是否泄露客户隐私？
- 是否存在夸大效果的前后对比？
- AI生成图片是否造成真实案例的误导？

## 04 话题标签检查

- 是否堆砌商业营销词？
- 是否使用夸大宣传标签？
- 是否存在不相关的行业标签？
- 是否利用敏感词吸引流量？

## 05 账号信息检查

- 昵称与实际认证主体是否一致？
- 简介是否存在联系方式？
- 是否存在虚构身份？
- 是否存在未经授权的品牌或机构背书？
- 是否与实际认证行业一致？

# 四、内容创作替换原则

今后创作内容时，统一采用以下原则：

1. 不夸大：不承诺无法证明的效果。
2. 不虚构：不编造案例、客户、身份、数据。
3. 不导流：不通过暗号、谐音、二维码等方式引导站外交易。
4. 不冒充：不伪造专业身份、权威背书和机构关系。
5. 不制造焦虑：不通过恐吓、身份攀比和阶层焦虑营销。
6. 不违规宣传：涉及金融、医疗、教育、房产等行业时，先核对资质与业务边界。
7. 不规避审核：不使用拼音、谐音、拆字和特殊符号掩盖违规表达。
8. 重视真实性：内容中的产品、服务、价格、效果和案例必须有事实依据。

**最终目标：让内容既能体现专业价值，也能保持真实、自然、可信，降低账号及商业推广的合规风险。**
